Quick summary

AVL Trees — revision summary

What is an AVL tree?

An AVL tree is a self-balancing binary search tree. For every node, the height difference between the left and right subtrees must remain within the allowed balance range.

Lecture · p.2

Why rotations happen

Insertions can make a subtree unbalanced. Rotations restore balance while preserving the binary-search-tree ordering.

Lecture · p.3Lecture · p.4

Rotation cases

Single rotations handle left-left and right-right imbalance. Double rotations handle left-right and right-left imbalance.

Why do we need a double rotation?
A double rotation is used when the imbalance bends in two directions — for example, a left-right case. One rotation first converts it into a straight imbalance, then the second restores balance while keeping BST ordering.
